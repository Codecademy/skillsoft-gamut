System props are grouped by the kind of styling they control. Import a group from `system` in `@skillsoft/gamut-styles`, or combine several with [compose](/foundations/system-props/compose-and-variants/).

- [Layout](/foundations/system-props/prop-groups/layout/) — dimensions, display, and alignment.
- [Space](/foundations/system-props/prop-groups/space/) — margin and padding on the spacing scale.
- [Typography](/foundations/system-props/prop-groups/typography/) — font family, size, weight, and line height.
- [Color](/foundations/system-props/prop-groups/color/) — foreground, background, and border colors.
- [Border](/foundations/system-props/prop-groups/border/) — border width, style, and radius on any side.
- [Flex](/foundations/system-props/prop-groups/flex/) — flexbox containers and items.
- [Grid](/foundations/system-props/prop-groups/grid/) — grid templates, placement, and gaps.
- [Background](/foundations/system-props/prop-groups/background/) — background images and patterns.
- [Positioning](/foundations/system-props/prop-groups/positioning/) — position, edges, and stacking order.
- [Shadow](/foundations/system-props/prop-groups/shadow/) — box and text shadows.
- [List](/foundations/system-props/prop-groups/list/) — list markers and their position.
