Shadow props add box and text shadows, using standard CSS shadow syntax.

```tsx
const ShadowExample = styled.div(system.shadow);

<ShadowExample
  boxShadow="0 0 4px rgba(0, 0, 0, .15)"
  textShadow="0 0 4px rgba(0, 0, 0, .15)"
/>;
```
