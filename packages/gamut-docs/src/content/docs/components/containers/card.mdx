## Usage

Use `Card` to present a piece of information as a distinct, contained surface, with animated hover/shadow treatment available when the whole card is clickable.

**Best practices:**

- Use `variant="default"` (the default) for a card on `surface-raised`, which follows the color mode. Use `variant="brand"` for a featured card on the brand gradient. Every card has a `border-subtle` hairline. The old color variants (`white`, `beige`, `navy`, `yellow`, `hyper`) are gone; for a dark card, wrap it in `<ColorMode mode="dark">`.
- Add `isInteractive` when wrapping `Card` in an `Anchor`. It applies an `'md'` border radius and the theme's raised shadow, and on hover a `state-hover` layer and a deeper shadow; a card with a pattern loses its pattern on hover. A card that isn't interactive has no shadow.
- `borderRadius` defaults to `'none'` (non-interactive) or `'md'` (`isInteractive`), and can be overridden — the outline/pattern shadow automatically matches whatever `borderRadius` is set.

**When NOT to use:**

- **A plain rectangular container with no color-mode-aware background, shadow, or hover treatment** — a plain [Box](/components/containers/boxes/box/) is enough.
